# Three-minute demo recording guide

The repository includes a live `make demo` text walkthrough. For a screen recording, start the application with `docker compose up --build`, open `http://127.0.0.1:8080`, and capture this sequence. Keep the synthetic-data notice visible and do not enter real customer information.

| Time | Screen/action | Narration |
|---|---|---|
| 0:00–0:25 | Open the priority queue and point to score/tier/reason-code columns. | “This is a fixed-seed synthetic portfolio. Cases are ranked using a visible balance, delinquency-age, and risk formula.” |
| 0:25–0:55 | Search or select the top case; show score components and case timeline. | “The detail page exposes the stored score breakdown and append-only case, contact, and promise history.” |
| 0:55–1:25 | Ask the copilot to explain the score/restrictions; show citations and template/provider label. | “The copilot retrieves policy text and recorded facts with citations. It is read-only and does not make scheduling or compliance decisions.” |
| 1:25–1:55 | Open Compliance & metrics; show findings, blocked rules, kept promises, and cure rate. | “Exceptions are traceable to rule IDs, while promise and cure metrics are computed from synthetic event records.” |
| 1:55–2:25 | Open a paused/suppressed case from the queue/API or run `make demo` in a terminal. | “A suppressed case remains visible for audit, but suppression prevents it from entering the contact queue.” |
| 2:25–2:50 | Show a blocked-contact decision and its policy reason. | “The scheduler records blocks for restrictions or invalid windows instead of attempting contact.” |
| 2:50–3:00 | End on the synthetic-data and legal-review disclaimer. | “This is a demonstration, not legal advice or a production collections system.” |

No recording file is generated by this repository; use a local screen-capture tool to record the walkthrough.
